# Dimah Academy - Student Result & Report Portal

A Progressive Web Application (PWA) built for **Dimah Academy** to manage class assessment records, auto-generate master result sheets, and print/export individual student academic report cards.

**School Address:** Opposite Street to Dafara Junction Road, Kuje Abuja  
**Motto:** ...knowledge and practice...

---

## Key Features

- **Form Teacher Authentication**: Secure login portal for form teachers.
- **Student Register**: Add, edit, and manage student bio-data.
- **Master Result Sheet**: Dynamic CA & Exam mark entry with real-time class averages and position ranking.
- **Student Report Cards**: Auto-calculated grades, total scores, class positions, and print/PDF ready formatting.
- **Progressive Web App (PWA)**: Works offline and can be added directly to the home screen of Android, iOS, or PC devices.

---

## How to Install on Mobile / PC

1. Open the live site URL in your web browser.
2. **Android (Chrome)**: Tap the 3 dots menu $\rightarrow$ Select **Add to Home Screen** or **Install App**.
3. **iPhone (Safari)**: Tap the Share button $\rightarrow$ Select **Add to Home Screen**.
4. **Desktop (Chrome/Edge)**: Click the Install icon in the browser address bar.

---

## Files Structure

- `index.html` - Core application layout, UI, and logic.
- `manifest.json` - PWA configuration settings for home screen installation.
- `sw.js` - Service Worker enabling offline capabilities.
- `logo.png` - Dimah Academy crest logo.
